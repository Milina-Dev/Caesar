# Caesar
## Caesar - шифрование и RLE-сжатие

## Описание проекта

Программа выполняет шифрование строки с помощью шифра Цезаря с ключом 3, сжатие полученной строки методом RLE, а затем проверяет возможность восстановления исходных данных.

## Возможности программы

1. Ввод строки, состоящей только из цифр (максимум 100 символов).
2. Проверка корректности введённых данных.
3. Шифрование цифр с помощью шифра Цезаря с ключом 3. После цифры 9 происходит переход к 0.
4. Сжатие зашифрованной строки методом RLE — подсчёт количества подряд идущих одинаковых символов.
5. Распаковка сжатой строки.
6. Расшифровка восстановленной строки.
7. Сравнение полученной строки с исходной для проверки правильности работы программы.

## Принцип работы программы

1. Пользователь вводит исходную строку из цифр.
2. Каждая цифра сдвигается на 3 позиции вперёд.
3. В зашифрованной строке подсчитываются группы подряд идущих одинаковых цифр.
4. Каждая группа записывается в виде цифры и количества её повторений.
5. Выполняется обратное преобразование: распаковка RLE и расшифровка Цезаря.
6. Восстановленная строка сравнивается с исходной.

## Особенности реализации

- Максимальная длина исходной строки — 100 символов.
- Допускаются только цифры от 0 до 9.
- При шифровании после 9 выполняется переход к 0.
- Между группами RLE используются пробелы для удобства чтения и однозначного разделения данных.
- После распаковки и расшифровки выполняется сравнение с исходной строкой.

## Запуск программы

Откройте проект в среде разработки и запустите программу. После этого введите строку, состоящую только из цифр.
